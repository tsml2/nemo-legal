# nemo-legal

Página estática de instruções de exclusão de dados (LGPD), servida por GitHub Pages.

**Não delete este repositório e não o torne privado.** A URL é referenciada externamente — pela Meta, no cadastro dos apps — e precisa continuar pública e no ar.

A URL é **https://thiagosalem.github.io/nemo-legal/**, servida por GitHub Pages a partir da `main`. Desligar Pages, tornar o repo privado ou arquivá-lo derruba a página e quebra o cadastro dos apps na Meta.

Mantenha o escopo: apenas o texto legal. Nada de configuração, credencial ou detalhe de infraestrutura aqui — este repositório é público.
